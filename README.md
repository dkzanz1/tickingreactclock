A real-time clock application built to explore React functional components, dynamic state manipulation, and hook lifecycle effects.

> **Context:** Constructed as a core hands-on exercise to master asynchronous state management, timer interval synchronization, and memory-safe cleanup patterns in modern React.

---

## 🛠️ Key Architectural & React Learnings

- **State & Lifecycle Synchronization:** Utilized `useState` and `useEffect` hooks to maintain accurate real-time time calculations without memory leaks.
- **Interval Management:** Implemented safe `setInterval` instantiation paired with proper cleanup functions on component unmount.
- **Component Componentization:** Structured isolated, reusable UI components for temporal data rendering and display formatting.

---

## 💻 Tech Stack

- **Frontend Core:** React, JavaScript (ES6+), HTML5, CSS3
- **Tooling & Quality:** Node.js, npm, GitHub Actions (Node.js CI runner)
